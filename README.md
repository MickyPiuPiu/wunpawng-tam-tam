# Wunpawng Tam Tam

A free, searchable research archive of Kachin (Wunpawng) materials: books, booklets, reports and articles about Kachin language, history and culture. Every record names its original author and source.

Live site: https://mickypiupiu.github.io/wunpawng-tam-tam

## How it works

- `index.html` is the whole website: home, search, record pages and about.
- `data/resources.json` is the archive's database, with one record per resource.
- `pdfs/` holds PDF files hosted on the site.

## Adding a record

1. Open the site's **Add a record** page (link in the footer), fill in the form, and press **Make record**.
2. Copy the result.
3. On GitHub, open `data/resources.json`, click the pencil icon, and paste the record inside the `[ ]` list. Every record except the last one needs a comma after its closing `}`.
4. If the record has a PDF, upload it to the `pdfs/` folder with the same file name you typed in the form.
5. Commit the change. The site updates in a minute or two.

Only add materials you have permission to share, and always credit the original creator.
